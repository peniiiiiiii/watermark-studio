# 浮水印工作台 · Watermark Studio

批次為照片加上設計過的浮水印。九種樣式、九宮格定位、原尺寸無損輸出。

**全程在瀏覽器裡處理，檔案不會上傳到任何伺服器。**

---

## 樣式

| # | 名稱 | 類型 | 說明 |
|---|---|---|---|
| 01 | 極簡字標 | 角落 | 寬字距、細字重、低透明度。不搶畫面。 |
| 02 | 底部漸層條 | 邊緣 | 漸層遮罩壓住雜訊，字放上面。位置選上排會翻到頂端。 |
| 03 | 膠囊標籤 | 角落 | 圓角膠囊。存在感明確但乾淨。 |
| 04 | 自訂 Logo | 角落 | 上傳自己的 PNG 標誌。 |
| 05 | 斜向暗紋 | 滿版 | 斜向重複平鋪，透明度壓低。最常見的防盜圖做法。 |
| 06 | 正交網格 | 滿版 | 不旋轉、隔行錯位。像正式文件的防偽底紋。 |
| 07 | 中央大字 | 滿版 | 中間一個大字，只有外框線不填色。 |
| 08 | 密集細字 | 滿版 | 字小、排密、透明度極低，像鈔票底紋。 |
| 09 | 四邊環繞 | 滿版 | 文字沿四邊繞一圈，中間完全留空。 |

## 功能

- 批次上傳最多 10 張，套用同一組設定
- 主標／副標文字即時編輯，九種樣式同步預覽
- 九宮格位置、尺寸滑桿、濃度滑桿、淺色印／深色印
- 每張可單獨複製到剪貼簿或下載，也可整批打包 ZIP
- 影片可取單格套用（尚不支援輸出影片檔）
- 手機版控制項收在底部彈出面板，單手可操作

## 畫質

- 照片解碼後以 **1:1 畫入畫布**，不縮放、不重新取樣，浮水印只疊在上層。
- 輸出尺寸完全等於原圖尺寸，沒有任何上限裁切。
- PNG 為無損編碼；另可選 JPEG 95 / WebP 95 以縮小檔案。
- 「複製」一律以 PNG 寫入剪貼簿，同樣無損。

## 使用

直接開 `index.html` 就能用，不需要安裝任何東西、不需要後端。

## 技術

單一 HTML 檔案，Canvas API，無相依套件。ZIP 以 store 模式自行組出，不引用外部函式庫。

## 已知限制

- iPhone 拍的 HEIC 檔瀏覽器解不開。到「設定 → 相機 → 格式」選「最相容」，或先轉存 JPG。
- 影片目前只做靜態單格預覽，不會輸出加了浮水印的影片檔。
- 輸出會移除 EXIF 等中繼資料（拍攝參數、GPS）。
- 畫布色彩空間為 sRGB，Display P3 廣色域照片會被轉換為 sRGB。
- 在 sandbox iframe（例如聊天室預覽）中下載會被瀏覽器擋掉，需在一般瀏覽器分頁開啟。
- PNG 原尺寸批次打包很吃記憶體，手機上 10 張大圖可能失敗，建議改用 JPEG。
